## 🔄 Update Process

Reports are automatically generated and published using:

1. **Snowflake MCP** integration for data querying
2. **Claude Code** for analysis and HTML generation
3. **Git** version control
4. **GitHub Pages** for hosting

To generate a new report, simply ask Claude Code with Snowflake access!

## 📈 How It Works

1. **Query Data:** Claude Code connects to Snowflake via MCP
2. **Analyze:** Processes data, calculates metrics, identifies trends
3. **Generate:** Creates professional HTML report with MyBambu branding
4. **Publish:** Commits to Git and deploys via GitHub Pages
5. **Share:** Report is live within ~1-2 minutes
